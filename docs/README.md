# GitHub Pages Website

This directory contains the GitHub Pages website for the GABA topology study.

## Local Development

To run the site locally:

```bash
cd docs
bundle install
bundle exec jekyll serve
```

Then visit http://localhost:4000/flywire-gaba-topology/

## Deployment

The site is automatically built and deployed by GitHub Pages when changes are pushed to the master branch.

## Structure

- `index.md` - Home page with overview and key findings
- `methods.md` - Detailed methodology
- `results.md` - Comprehensive results
- `code.md` - Code documentation and reproducibility guide
- `_config.yml` - Jekyll configuration
- `assets/css/style.scss` - Custom styling

## Theme

Uses the Cayman theme with custom styling for a modern, professional appearance.
